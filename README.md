# 2026 Fall Registration

一个社团招新注册墙的物理模拟可视化展示。

它同时也是一个 Git 练手项目，旨在帮助新成员熟悉 **Fork**、**Commit** 和 **Pull Request** 的开源协作流程。通过提交 PR，可以将自己的头像和简介加入到这个炫酷（？）的物理世界中！

点击网址查看效果：

https://source-of-ustb.github.io/2026-registration/

在网址中点击头像可以查看个人信息，并且可拖拽社团成员的头像并发生碰撞。

## 互动玩法

- **自由碰撞**：拖动或轻点头像，支持重力开关、搅动、暂停和重新排列。头像随碰撞和偏心拖拽自然旋转，姓名保持正向。窗口缩放后，头像和物理边界会一起适配。
- **物理下落赛**：3 秒倒计时后，头像在 12 段机关组成的长赛道中受重力下落，与弹柱、斜坡、旋转挡板、横移撞锤、摆杆、往返滑闸和其他头像发生碰撞，按实际到达底部终点的顺序排名。支持镜头自动跟随、查看全程、暂停、重赛和退出。
- **合成大西瓜**：每局随机抽取最多 11 位成员，组成从小到大的头像等级。点击投放，或拖动瞄准后松手；两个相同头像碰撞后会合成下一级并得分。支持下一个头像预览、合成路线、本机最高分、暂停和随机重开。头像持续堆过警戒线时结束，最大头像会保留供继续挑战高分。聚焦画布后可用左右方向键瞄准、空格或 Enter 投放。
- **成员列表**：按名字、简介或兴趣标签搜索成员，查看个人介绍和社交链接。
- 主页采用浅色 Dashboard 布局，成员墙与比赛在同一页完成；桌面和手机布局自适应。比赛或暂停时可在画布上上下滑动页面。

## 🛠️ 本地开发与构建

```shell
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务器 (实时预览修改)
npm run dev

# 3. 构建生产版本 (用于部署)
npm run build

# 4. 预览构建产物
npm run preview

# 5. 运行物理边界、比赛与合成逻辑回归测试
npm test
```

## 🚀 快速开始

1. Fork 本仓库
2. 填写你的个人信息到 `data/members/`
3. 提交 Pull Request (PR)
4. 等待合并，查看你的头像出现在墙上
